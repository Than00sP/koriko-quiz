# Koriko Quiz — ช่วงนี้คุณอยู่ในโหมดไหน?

เกม quiz พิกเซล ไม่มีอะไรต้องติดตั้ง ไม่ต้องใช้เน็ต เปิด `index.html` ในเบราว์เซอร์ได้เลย · จอคอม/แนวนอนใช้เลย์เอาต์ 1280×720 · มือถือแนวตั้งสลับเป็นเลย์เอาต์แนวตั้งให้อัตโนมัติ (หมุนจอแล้วเปลี่ยนตาม)

## อัปขึ้น GitHub Pages (ทางเว็บ ~5 นาที)
1. ไปที่ github.com แล้วกด **New repository** → ตั้งชื่อ เช่น `koriko-quiz` → เลือก **Public** → กด Create
2. ในหน้า repo กด **uploading an existing file** → ลาก**ไฟล์ทั้งหมดในโฟลเดอร์นี้**ไปวาง (`index.html` · `data.js` · `art.js` · `packs.js` · `quiz.js` · โฟลเดอร์ `fonts`) → กด Commit
   - ⚠️ `index.html` ต้องอยู่ชั้นบนสุดของ repo ห้ามซ้อนอยู่ในโฟลเดอร์ `game/`
3. **Settings → Pages** → Source = *Deploy from a branch* → Branch = `main` · `/ (root)` → Save
4. รอ 1–2 นาที ลิงก์จะเป็น `https://<ชื่อผู้ใช้>.github.io/koriko-quiz/`

## ทางลัดตอนพรีเซนต์
- เติม `?r=ME` / `?r=YOU` / `?r=MORE` / `?r=TOGETHER` ท้ายลิงก์ = ข้ามไปหน้าผลโหมดนั้นเลย
- เติม `&cut=1` ด้วย = ดูฉากเชฟชักดาบก่อนเข้าหน้าผล
- ปุ่ม ♪ มุมขวาบน = ปิดหรือเปิดเสียง
